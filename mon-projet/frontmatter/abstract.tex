\section*{Présentation du Manuel}

Ce document constitue un tutoriel interactif et auto-documenté
dédié à la maîtrise d'une architecture \LaTeX{} professionnelle, modulaire et découplée,
fondée sur la classe de référence \code{scrbook} de l'écosystème KOMA-Script.
Le lecteur y trouvera une dissection méthodique de l'arborescence du projet,
explicitant le rôle spécifique de chaque composant :
l'ordonnancement par le fichier maître (\code{main.tex}),
l'encapsulation de la mise en page dans la classe personnalisée (\code{mythesis.cls}),
la bascule instantanée entre profil d'affichage écran et profil d'impression reliée via les fichiers d'options (\code{.clo}),
ainsi que la configuration fine des styles bibliographiques (\code{.bbx}/\code{.cbx}).
L'ouvrage fournit des instructions pratiques pour personnaliser la palette chromatique,
enrichir les macros de rédaction, exploiter les schémas vectoriels TikZ
et automatiser la compilation via \code{latexmk} en isolant les fichiers temporaires dans un sous-dossier dédié.

\vspace{0.8em}
\noindent\textbf{Mots-clés :} Tutoriel \LaTeX{}, KOMA-Script, classe \code{scrbook}, architecture modulaire, profils \code{.clo}, Bib\LaTeX{}, compilation \code{latexmk}.

\begin{otherlanguage}{english}
\section*{Handbook Overview}

This manuscript is a hands-on, self-documenting tutorial designed to master a modern, modular,
and fully decoupled \LaTeX{} publishing architecture built upon KOMA-Script's \code{scrbook} class.
Through a detailed walk-through of the project tree, this guide explains the exact purpose of every file:
document orchestration in \code{main.tex},
semantic styling encapsulation within the custom class (\code{mythesis.cls}),
seamless switching between interactive screen reading and binding-ready print versions via class option files (\code{.clo}),
and fine-grained citation and bibliography tailoring (\code{.bbx}/\code{.cbx}).
Practical recipes demonstrate how to adapt color palettes, develop custom mathematical macros,
embed scaled vector TikZ diagrams, and automate zero-friction builds using \code{latexmk} with out-of-source compilation in a dedicated directory.

\vspace{0.8em}
\noindent\textbf{Keywords :} \LaTeX{} tutorial, KOMA-Script, \code{scrbook} class, modular architecture, class options \code{.clo}, Bib\LaTeX{}, \code{latexmk} workflow.
\end{otherlanguage}
